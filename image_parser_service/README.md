# image_parser_service — парсинг товаров с картинок

Подсервис извлекает данные о товарах (название, цена, объём/вес, бренд) из фото и скриншотов (jpg, jpeg, png). Текст распознаётся локальным OCR Tesseract. Результат — список словарей с тем же набором ключей, что у остальных парсеров проекта.

Это не парсер сайта: у него нет URL и он не участвует в цикле `main.py` по реестру `config.parsers`. Вызывается явно из кода или из командной строки.

## Состав

| Файл | Назначение |
|---|---|
| `image_parser_service.py` | Точка входа `main()`: перебор файлов, сборка строк, `update_retail_points` |
| `image_parser_utils.py` | Определение формата, предобработка, OCR, извлечение цены/объёма/названия/бренда |
| `ocr_setup.py` | Установка и проверка Tesseract и языковых данных (`rus`, `eng`) |
| `tessdata/` | Языковые данные, появляются при настройке. В git не попадают |
| `debug_dump/` | Сырой OCR-текст по каждому файлу, только при `debug_mode=True`. В git не попадает |

## Установка (один раз на машину)

Нужны Python-пакеты из `requirements.txt` (`pillow`, `pytesseract`) и системный Tesseract. Tesseract — отдельная программа, pip её не ставит.

```
.\venv\Scripts\python.exe -m image_parser_service.ocr_setup
```

Скрипт:

1. Ищет `tesseract.exe` в PATH и в `C:\Program Files\Tesseract-OCR\`, `C:\Program Files (x86)\Tesseract-OCR\`, `%LOCALAPPDATA%\Programs\Tesseract-OCR\`.
2. Если не найден — ставит через `winget install UB-Mannheim.TesseractOCR`. Может появиться окно UAC, его нужно подтвердить.
3. Скачивает `rus.traineddata` в `image_parser_service/tessdata/` и проверяет SHA-256. Повторный запуск файл не качает.
4. Копирует `eng.traineddata` из установки Tesseract в ту же папку.
5. Печатает отчёт построчно: `[OK]` или `[ERR]`. Код выхода `0` — всё готово, `1` — нет.

Флаг `--no-install` отключает установку Tesseract, оставляет только проверку и скачивание языковых данных.

Если скрипт упал на шаге 2, поставь Tesseract вручную с https://github.com/UB-Mannheim/tesseract/wiki и запусти скрипт ещё раз. Он подхватит уже установленный Tesseract.

## Быстрый запуск

1. Положи картинки в папку `images_input/` в корне проекта.
2. Из корня проекта:

```
.\venv\Scripts\python.exe -m image_parser_service.image_parser_service
```

Запускать как модуль (`-m`) из корня проекта обязательно. Прямой запуск файла (`python image_parser_service\image_parser_service.py`) падает с `ImportError`, потому что модуль использует относительные импорты.

Без картинок выйдет `Источник 'images_input' не содержит файлов jpg/png` и `rows: 0`.

## Вызов из кода

```python
from image_parser_service.image_parser_service import main

rows = main(
    source=r"C:\scans\prices",
    shop_name="Ярче!",
    city="Москва",
)
```

Параметры (все необязательны):

| Параметр | Что принимает | Значение по умолчанию |
|---|---|---|
| `source` | папка, путь к одному файлу или список путей | `config.image_source`, иначе `"images_input"` |
| `shop_name` | значение поля «Сеть» | `config.image_shop_name`, иначе `"Скан изображений"` |
| `city` | значение поля «Адрес Торговой точки» | `config.image_city`, иначе `""` |

Относительный путь `images_input` считается от текущей папки запуска. Из корня проекта это работает, из других мест — нет. Лучше передавать абсолютный путь.

## Настройка через config.py

```python
image_source = r"C:\scans\prices"
image_shop_name = "Ярче!"
image_city = "Москва"
image_known_brands = ["Домик в деревне", "Балтика", "Хеннесси"]
debug_mode = True
```

Затем `main()` без аргументов.

## Как работает обработка

Для каждого файла по очереди:

1. **Список файлов.** Из папки берутся `.jpg`, `.jpeg`, `.png` в алфавитном порядке. Из списка или одиночного пути — как есть.
2. **Формат.** Pillow читает содержимое файла. Допустимы только `JPEG` и `PNG`. Файл с другим расширением или битый пропускается с сообщением.
3. **Предобработка.** Перевод в оттенки серого, автоконтраст, апскейл до ~1800 px по ширине, если картинка меньше 900 px, резкость.
4. **OCR.** Tesseract с языками `rus+eng`.
5. **Цена.** Сначала ищется число с меткой `руб`, `р.` или `₽`, иначе первое число вида `XX,XX` или `XX.XX`. Запятая становится точкой. Ноль и ничего не найденное дают пропуск файла, а не `0`.
6. **Объём и вес.** Тот же шаблон, что в остальных парсерах: `мл`, `л`, `кг`, `г` после числа. Перед поиском исправляется частая ошибка OCR: латинская `n` или `l` сразу после цифры превращается в `л`. Литры и миллилитры идут в `Объем`, граммы и килограммы — в `Вес`.
7. **Название.** Из строк текста убираются цена и символ `₽`, остаётся самая длинная содержательная строка. Если название не нашлось, файл пропускается.
8. **Бренд.** Берётся только из `image_known_brands` — вхождением в текст. Угадывания нет, поэтому без списка брендов поле пустое.
9. **Строка результата.** Формируется словарь с фиксированным набором ключей.

Пропущенные файлы попадают в лог с причиной: неподдерживаемый формат, ошибка распознавания, цена не распознана, название не распознано.

После обработки вызывается `update_retail_points(shop_name, city, 1)` в `try`, как и в остальных парсерах.

## Формат результата

Список словарей. Ключи одинаковы во всех строках:

| Ключ | Что в нём |
|---|---|
| `Сеть` | `shop_name` |
| `Тип магазина` | `"Скан"` |
| `Адрес Торговой точки` | `city` |
| `Бренд` | из `image_known_brands`, иначе пусто |
| `Название продукта` | распознанное название |
| `Цена` | `float` |
| `Цена по акции` | `0` |
| `Фото товара` | `file://`-URI исходной картинки |
| `Ссылка на страницу` | пусто |
| `Объем` | например `"0.5 л"` или пусто |
| `Вес` | например `"950 г"` или пусто |
| `Остаток` | всегда `"1"` (товар есть на фото) |
| `Категория` | пусто |
| `Рейтинг` | `0.0` |
| `Номер` | порядковый номер строки, с 1 |

## Отладка

При `debug_mode = True` сырой текст OCR каждого файла сохраняется в `image_parser_service/debug_dump/<имя файла>.txt`. По нему видно, что Tesseract реально прочитал, и понятно, почему файл пропущен.

## Типичные проблемы

| Симптом | Причина | Что сделать |
|---|---|---|
| `Tesseract не настроен — запусти: python -m image_parser_service.ocr_setup` | Tesseract не найден или нет `eng`/`rus` | Запустить `ocr_setup` |
| `Error opening data file ... rus.traineddata` | Языковые данные не в той папке | Запустить `ocr_setup`, он положит их в `tessdata/` |
| Все файлы пропущены с «цена не распознана» | Мелкий или размытый текст, цена без метки валюты | Фото крупнее и резче; проверить `debug_dump` |
| Бренд пустой | Бренда нет в `image_known_brands` | Добавить бренд в список |
| `Объем` перепутан или пуст | OCR не распознал единицу | Проверить `debug_dump`, при необходимости расширить правила в `extract_measure` |
| `rows: 0` без ошибок | Папка пустая или нет jpg/png | Проверить путь и расширения |

## Ограничения

- Точность зависит от качества фото. Ровный свет, без бликов и наклона даёт лучший результат. Мелкий текст и размытие дают промахи.
- Извлечение названия эвристическое. На сложной вёрстке может взять не ту строку.
- Бренд без списка не определяется.
- Остаток фиксирован как `"1"`. По фото наличие на полке не проверить.
- Tesseract ставится только на Windows через winget; на других системах установка вручную.
